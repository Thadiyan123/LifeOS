LifeOS privacy policy

Last updated: 10 October 2026

Who uses LifeOS

LifeOS is a single-user personal tool. Its only user is its owner, Rahul Krishnan. It doesn't offer accounts to anyone else and doesn't collect data about other people.

What data it accesses

With the owner's consent through Google sign-in, LifeOS uses the YouTube API Services to:

  • upload videos, thumbnails and video details to the owner's own YouTube channels;
  • read those channels' identity, video status, and analytics and reporting data;
  • read public comments on the owner's own videos, to summarise viewer feedback for the owner.

How the data is stored and used

  • OAuth tokens are stored only on the owner's computer, in Windows Credential Manager.
  • Analytics and video data are stored in a local database on that computer, and used only to help the owner decide what to make next.
  • No data is sold, shared with third parties, or used for advertising.
  • Local data is kept as long as the owner needs it and can be deleted by the owner at any time.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google and YouTube policies

LifeOS uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
